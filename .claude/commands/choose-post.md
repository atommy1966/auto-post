sns/x/ の中から chosen_x: が設定されていない下書きを探し、X と Threads それぞれに A/B を選んでください。

## 手順

1. `sns/x/` のファイルを確認し、フロントマターに `chosen_x:` がないファイルを一覧表示する
2. 未選択ファイルがなければ「未選択の記事はありません」と報告して終了する
3. 未選択ファイルが1件以上あれば、1件ずつ次の手順で処理する：
   - X用・Threads用それぞれのパターンA・Bの本文をチャットに表示する
   - `AskUserQuestion` ツールを使い、X用（A/B）とThreads用（A/B）を1回の質問でまとめて選択させる
     - 選択肢のラベルにはパターン本文の冒頭15字程度を含める（例: `A — JASRACが284億円…`）
4. 選択が完了したら：
   - `sns/x/ファイル名.md` のフロントマターに `chosen_x:` と `chosen_threads:` を追記する
   - `sns/threads/ファイル名.md` にも同じ値を追記する
   - `bash scripts/buffer-post-all.sh テーマ名` を実行して投稿する
   - 次の未選択ファイルがあれば同じ手順を繰り返す

5. すべて完了したら、今回選んだ記事とパターンの一覧を報告する

## フィールドの追記位置

フロントマターの `note_url:` の次の行に追加する：
```
note_url: https://...
chosen_x: B
chosen_threads: A
```
